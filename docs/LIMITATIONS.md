# 已知限制

## 环境与验证

- 主要使用环境是 Windows、SnowLuma 和 DSH Desktop。目前只在 Windows 11 x64 + DSH Desktop 0.2.1-rc.2 上做过实机验证；DSH 0.20 在 0.2.1 的改动之后没有重新跑完整回归，macOS 和 Linux 从没上过真机，这三类都不支持。换别的 DSH 构建、模型供应商或网络环境，不保证端到端跑得通；升级 DSH 或 SnowLuma 之后要重新测一遍。具体范围见[兼容性与支持范围](COMPATIBILITY.md)。
- 自动化测试通过只能证明覆盖到的条件；不能代替真实 QQ 登录、消息收发、模型调用、贴吧访问和长时间运行测试。
- QQ 客户端重启后可能需要重新接入或注入 SnowLuma。桥接无法保证在关机、休眠或上游未接入期间完整接收消息；内存队列也不能代替持久消息队列。
- 连接端口可能被占用或被系统限制；变更端口后需要让 SnowLuma 与桥接配置一致。

## 模型和会话

- 529/503 提示依赖 DSH 实际产生并送达的重试事件；桥接只观察事件，不自行重放回合，也不能保证每次上游故障都出现对应提示。
- 本发布包不提供余额或额度为零的专项检测、限次提醒、请求阻断或自动恢复。限流、网络故障与真实额度耗尽也不应一概等同。
- 当前自动转发文本的分支只处理 `completed` 回合；如果回合因 `max-tokens` 等非正常状态结束，已生成的部分文本可能不会自动发到 QQ，也没有针对该状态的专门提示。这是源码层已知限制，不代表每次无回复都是这个原因；二代仿真本来就以发送工具而非自动转发文本为主。
- 会话卡忙自愈、断线恢复和长等待处理都有边界；网络中断、异常事件顺序或模型长时间无响应时仍可能需要人工检查。不要假设看门狗可以恢复所有情况。
- 模型输出、工具使用和人格表现受模型能力与配置影响；人格提示不是安全边界。不要仅凭提示词授予高风险权限。

## 贴吧与多媒体

- 贴吧功能只读，依赖第三方页面结构、网络、登录状态及平台规则；页面变化、安全验证、过期 Cookie 或频率限制都可能导致失败。搜索降级不等于完整帖子内容。
- 帖子图片能否读取、模型能否理解，受图片来源、大小和模型多模态能力限制。发送图片也受来源白名单和大小限制。
- 语音默认关闭，发布包不包含个人音频；使用前需自行准备音频和相关配置。

## 隐私与权限

- `config.json`、`state/`、DSH 凭据、Cookie、控制台令牌、个人音频和日志可能含私人信息，不应公开。备份及排障时同样需要控制访问范围。
- 共享记忆会跨授权会话使用；启用前应考虑参与者隐私。跨会话代发仅在程序限定的授权条件下工作，仍应谨慎配置管理员和白名单。
- 项目代码和第三方组件许可不同；特别是 SnowLuma 及其 SDK/MCP 依赖，请先阅读 [LICENSE](../LICENSE)。
